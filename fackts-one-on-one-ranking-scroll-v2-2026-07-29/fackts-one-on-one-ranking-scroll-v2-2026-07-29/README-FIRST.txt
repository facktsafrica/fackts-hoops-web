FACKTS 1V1 MOBILE RANKING SCROLL V2

WHY V2 IS NEEDED
The first ranking-scroll installer could leave the visible phone table unchanged.
V2 replaces the complete mobile Rankings component and uses a real wide table
with direct browser scrolling rules.

WHAT WILL CHANGE ON PHONES
- A visible "Swipe sideways for all stats" guide appears.
- Rankings can be swiped left and right.
- The contestant list can be scrolled up and down inside the table.
- All 10 columns are available:
  Rank, Player, P, W, D, L, PF, PA, +/-, Win %.
- The header stays visible while scrolling down the contestants.

WHAT WILL NOT CHANGE
- Battle cards, dates, player names, positions, scores and photos.
- The desktop Rankings design.
- Any notification files.

HOW TO INSTALL
1. Move this extracted folder inside fackts-hoops-web.
2. Double-click APPLY-1V1-RANKING-SCROLL-V2.cmd.
3. After SUCCESS, stop any running dev server with Ctrl+C.
4. Run npm run dev again.
5. Open http://localhost:3000/one-on-one in phone view.
6. Hard-refresh with Ctrl+Shift+R.
7. Check for the swipe guide, then swipe inside Rankings.

The installer changes only app\one-on-one\page.tsx and creates a backup.
Do not push until the localhost result has been checked.
