FACKTS PLAYERS MOBILE V5

This tiny correction removes the broken encoding characters from mobile player
nicknames and separators.

It does not change:
- mobile card layout
- player data or Supabase queries
- desktop cards
- animations
- any other page

HOW TO APPLY
1. Open this extracted folder.
2. Press Alt + D.
3. Type cmd and press Enter.
4. Type APPLY-V5.cmd and press Enter.
5. Wait for SUCCESS.
6. Refresh /players with Ctrl + Shift + R.

Nothing is pushed online.

To undo this correction, run RESTORE-V5.cmd in the same way.
