FACKTS 1V1 MOBILE RANKING SCROLL

WHAT THIS FIXES
- Phone users can swipe sideways through every ranking statistic.
- Phone users can scroll vertically through every contestant.
- The ranking header remains visible while the contestant list scrolls.
- Mobile now includes all 10 columns: position, hooper, played, wins,
  draws, losses, points for, points against, point difference and win rate.
- Desktop rankings remain unchanged.

HOW TO INSTALL
1. Move this extracted folder inside the fackts-hoops-web project.
2. Double-click APPLY-1V1-RANKING-SCROLL.cmd.
3. After SUCCESS, run npm run dev.
4. Open http://localhost:3000/one-on-one in phone view.
5. Hard-refresh, then swipe vertically and sideways inside Rankings.

The installer changes only app\one-on-one\page.tsx and creates a backup.
Do not push until the phone layout has been checked.
