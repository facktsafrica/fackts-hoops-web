FACKTS PLAYERS MOBILE V4

WHAT THIS PATCH CHANGES
- Mobile player row only
- Full player name gets first priority
- Full position appears under the name
- GP / PPG / RPG / APG labels stay on one straight line
- All four values stay on one straight line
- Mobile card height is 100px

WHAT THIS PATCH DOES NOT CHANGE
- Supabase queries
- Player records or stats
- Desktop/laptop cards
- Animations
- Any other page

HOW TO APPLY
1. Open this extracted folder.
2. Press Alt + D.
3. Type: cmd
4. Press Enter.
5. In the black window type: APPLY-V4.cmd
6. Press Enter.
7. Wait for SUCCESS.
8. Refresh http://localhost:3000/players using Ctrl + Shift + R.

HOW TO UNDO
Repeat steps 1 to 4, then run: RESTORE-V4.cmd
