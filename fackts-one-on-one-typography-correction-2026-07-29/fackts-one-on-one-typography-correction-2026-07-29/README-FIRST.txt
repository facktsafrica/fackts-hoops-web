FACKTS 1V1 TYPOGRAPHY CORRECTION
================================

This corrects the previous mobile polish:

- restores the battle-row height and breathing room
- restores the player-photo size
- makes player names smaller and less heavy
- makes player positions smaller and quieter
- keeps the COMPLETED/status-header fix
- keeps the score and 1V1 centre area unchanged
- keeps desktop styling unchanged

INSTALL
-------

1. Put this extracted folder inside fackts-hoops-web.
2. Double-click APPLY-1V1-TYPOGRAPHY-CORRECTION.cmd.
3. Wait for the green success message.
4. Run npm run dev.
5. Open http://localhost:3000/one-on-one in phone view.
6. Hard-refresh and send a screenshot before pushing.

Only app\one-on-one\page.tsx is changed.
An automatic backup is created before installation.
