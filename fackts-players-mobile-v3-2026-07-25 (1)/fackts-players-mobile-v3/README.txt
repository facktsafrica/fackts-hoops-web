FACKTS PLAYERS MOBILE V3

1. Extract this ZIP.
2. Open the extracted fackts-players-mobile-v3 folder.
3. Double-click APPLY-V3.bat.
4. Wait until the black window says SUCCESS.
5. Refresh http://localhost:3000/players with Ctrl + Shift + R.

Do not open page.tsx.
Do not run a PowerShell script.

This changes only app\players\page.tsx and creates a backup:
app\players\page.before-mobile-v3.tsx

To undo, double-click RESTORE-ORIGINAL.bat.
