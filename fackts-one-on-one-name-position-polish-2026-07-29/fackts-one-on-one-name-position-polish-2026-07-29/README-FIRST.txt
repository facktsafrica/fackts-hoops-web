HOW TO INSTALL

1. Move this extracted folder inside fackts-hoops-web.
2. Double-click APPLY-1V1-NAME-POSITION-POLISH.cmd.
3. Run npm run dev.
4. Open http://localhost:3000/one-on-one in phone view.
5. Hard-refresh with Ctrl + Shift + R.
6. Check the player names and positions before pushing.

The installer creates a timestamped backup before changing the page.
